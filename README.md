# Student Performance Analytics & Report Generator

A practical Python project that reads student scores from CSV, validates the data, calculates student and subject averages, ranks students, and exports a structured JSON report.

## What it demonstrates
- Functions and clean separation of tasks
- Lists, dictionaries and sorting
- CSV and JSON file handling
- Data validation and error handling
- Aggregation and basic reporting

## Run
```bash
python student_analytics.py
```

## Interview talking points
1. **Problem:** Turn raw student scores into a useful class report.
2. **Flow:** Load CSV -> validate scores -> calculate averages -> rank students -> save JSON report.
3. **Key Python concepts:** functions, dictionaries, loops, sorting with `lambda`, file handling.
4. **Improvement idea:** connect the program to MySQL or add charts later.
